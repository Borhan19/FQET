The original ten manuscript plotting CSVs are hosted at the public GitHub
release `Borhan19/QThEngineering` tagged `v1.0-submission`.

To download the release-commit copies for the existing plotting script:

    python fetch_reference_data.py --into data

The reconstructed calculations are separate and generate results under `results/`.
Never overwrite the original CSVs with outputs from a reconstructed optimizer
unless a full independent scientific comparison has been completed.
